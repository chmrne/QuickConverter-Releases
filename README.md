\## v0.1.0



QuickConverter is a lightweight Windows utility for converting between PDF and image files.



\### Features



\*\*\*PDF → JPG — Convert every page of a PDF into a separate JPG image.

\*\*\*JPG/PNG → PDF — Convert an image into a PDF document directly from the console application.

\*\*\*Convert using a file path — You can enter the full path of your PDF or image manually, making it possible to use the converter without any special file selection window.

\*\*\*Windows right-click integration — Right-click any PDF file in Windows Explorer and select \*Quick Converter\* to start the PDF → JPG conversion automatically. The selected PDF is passed directly to the application.

\*\*\*Automatic page handling — Multi-page PDFs are converted page by page, with each page becoming its own JPG image giving you the ability to name it while the application is running.

\*\*\*Bundled Java runtime — Java is included with the application, so users don't need to install Java separately.

\*\*\*Windows installer — Install QuickConverter like a normal Windows application.

\*\*\*Easy uninstallation — Uninstalling QuickConverter also removes its Windows right-click integration.



\### Requirements



Windows 10/11.
